Implement H01–H08 of concept v2 for a facilitator-led workshop. Preserve existing workspace IDs and private data. Provide a complete journey from two-field idea capture through use-case design, value estimation, pilot decisions, manual results and team enablement.

Use Eraneos charcoal, warm neutrals and orange with explicit legends. Prioritize a responsive, readable workbench, contextual detail editor, opportunity landscape, comparison and printable decision brief. Unknowns must remain distinct from low scores, and capacity value from cash savings.

Add hash routes, draft protection, explicit save states and recoverable version conflicts. Back up the backend before deployment and rehearse schema normalization on a private copy. Keep the existing global-revision concurrency model for the designated-scribe release. No claim of individual authorization or multi-editor collaboration.

Acceptance: capture and persist an idea; develop a linked use case without retyping; save unknown and measured values correctly; plan a baseline experiment, record a decision and observation; link an objective, target node and enablement action; inspect heatmap contributing records; compare candidates; export a brief. Test calculations, validation, migration, retry and conflicts; verify the published frontend.

Excluded: H09 autonomous proposal workflows and H10 identity/storage expansion. Existing read-only assistant remains available. Sample content must be explicitly marked and remain separate from live records.
